⭐ PART 3 — Login Screen Documentation
✔ Purpose

Authenticate user using backend API:

POST /auth/login

✔ Required user input

Email

Password

✔ After login

Store JWT token in localStorage

Store tenantId in localStorage

Redirect to Dashboard

📌 Technical Requirements (Frontend)
API Setup

Login endpoint:

POST /auth/login
{
  "email": "admin@gmail.com",
  "password": "123456"
}


Backend returns:

{
  "token": "jwt-token-here"
}

📌 Logic Flow

User enters email/password

You call AuthApi.login()

If success:

Save token to localStorage

Save tenantId:

either user enters

or from login response

Redirect to /dashboard

📌 Login API Wrapper

src/api/authApi.ts

import axiosClient from "./axiosClient";

export const AuthApi = {
  login: (payload: { email: string; password: string }) =>
    axiosClient.post("/auth/login", payload),
};
