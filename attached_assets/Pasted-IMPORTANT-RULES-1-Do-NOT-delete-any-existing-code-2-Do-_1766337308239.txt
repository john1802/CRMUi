1️⃣ PURPOSE OF ENTITY UI

The Entity UI represents Modules / Objects in the CRM.

Examples:

Leads

Contacts

Products

Orders

This UI allows the user to:

View all entities

Open an entity

Load its dynamic definition (fields + lookups)

(Optional Admin) Create / Edit / Delete entities

2️⃣ BACKEND ENDPOINTS SUMMARY (SOURCE OF TRUTH)
Method	Endpoint	Purpose
POST	/api/entities	Create entity
GET	/api/entities	List entities
GET	/api/entities/{id}	Get entity by ID
GET	/api/entities/slug/{slug}	Get entity by slug
PUT	/api/entities/{id}	Update entity
DELETE	/api/entities/{id}	Delete entity
GET	/api/entities/{id}/definition	Load UI metadata
3️⃣ UI SCREENS REQUIRED (ENTITY ONLY)

Fields
